# Домашняя работа №6: JavaScript и первый компонент React

**Тема:** книжная полка. **Время:** примерно 60–90 минут.

Закрепи объекты, массивы, функции, `filter`, `map` и вывод данных в React. React-часть — небольшой первый шаг к следующей презентации. Не нужны backend, база данных, HTTP-запросы, формы или useState.

В репозитории — стартовый проект с TODO, не готовое решение. Объяснения и примеры на другой теме находятся в [EXPLANATIONS.md](EXPLANATIONS.md).

## Запуск

Нужны Node.js 24 LTS и pnpm 11.25.0 (те же инструменты, что в курсе). Если pnpm ещё не установлен и доступен npm: `npm install --global pnpm@11.25.0`.

Сделай fork, клонируй свой репозиторий и открой его папку в VS Code. Выполняй из папки, где лежит package.json:

```text
pnpm install --frozen-lockfile
pnpm dev
```

Открой адрес, который напечатает Vite, обычно http://127.0.0.1:5173 . При редактировании исходников страница обновляется. Не открывай index.html двойным щелчком. Остановить сервер — Ctrl+C.

Стартовая страница показывает подсказку и общее число исходных книг. Это специально ещё не результат домашки. Функции в utils.js возвращают пустые массивы, пока ты не заменишь TODO.

## 1. Подготовь данные — 10 минут

В [src/books.js](src/books.js) уже есть три книги. Добавь ещё две, сохрани структуру объектов:

```javascript
{ id: 4, title: "Название книги", price: 1200, inStock: true }
```

- У каждой книги уникальный числовой id.
- title — строка, price — число, inStock — boolean (`true` или `false`, без кавычек).
- Итоговый массив содержит пять книг. Хотя бы одна недоступна.

## 2. Реализуй две функции — 20 минут

Открой [src/utils.js](src/utils.js).

### getAvailableBooks(books)

Верни новый массив только доступных книг — с `inStock === true`. Используй `filter`. Порядок исходных книг сохраняется.

### getBookTitles(books)

Верни новый массив названий всех переданных книг. Используй `map`. Эта функция сама не фильтрует наличие.

Для обеих функций пустой вход `[]` должен давать `[]`. Исходный массив и объекты не изменяй. Функции используют свой параметр, а не импортируют общий books из другого файла. Из параметров передаются корректные массивы книг — сложную проверку типов писать не нужно.

Проверь вручную:

```text
pnpm demo
```

Команда выполняет [src/check.js](src/check.js), печатает результаты и случаи с пустым массивом. Это демонстрация для ручной проверки, не автоматические тесты. При необходимости добавь временные console.log.

## 3. Покажи данные в React — 25–35 минут

Доработай [src/App.jsx](src/App.jsx):

1. Оставь заголовок «Книжная полка».
2. Импортируй getAvailableBooks из utils.js и вызови её с массивом книг.
3. Покажи **количество доступных книг**, вычислив его из результата функции.
4. Через `map` выведи только доступные книги: название и цену с символом ₸.
5. Каждому элементу списка передай `key={book.id}`.
6. Удали стартовую подсказку про TODO после выполнения.

Пример результата для исходных трёх книг, до твоих дополнений:

```text
Книжная полка
Доступно книг: 2

Маленький принц — 1500 ₸
Алиса в Стране чудес — 1800 ₸
```

После добавления своих книг результат будет другим. Не записывай вручную число доступных книг и строки списка. При временной замене исходного массива на `[]` страница должна показывать 0 и не падать. Отдельное сообщение о пустом списке — по желанию.

## 4. Добавь стили и ответы — 15–25 минут

Доработай [src/styles.css](src/styles.css): отступы, читаемый текст, ограничение ширины. Проверь узкий экран: страница помещается по ширине, длинные названия переносятся.

Заполни [ANSWERS.md](ANSWERS.md). Перед сдачей выполни:

```text
pnpm build
```

Проверь Console браузера: нет ошибок и предупреждений о key. Убедись, что изменённое inStock после сохранения файла меняет список и счётчик.

**Необязательное дополнение:** вынеси одну книгу в компонент BookCard и передавай объект книги через props.
